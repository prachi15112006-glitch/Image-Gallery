# Image Gallery

A responsive and interactive image gallery website built using HTML, CSS, and JavaScript.

## Features

- Search images by name
- Category-based image filtering
- Lightbox for viewing images
- Magnifying glass search icon
- Displays a "No image found" message for unavailable searches
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## About the Project

This project was created to practice frontend web development and learn how to build an interactive and responsive image gallery using HTML, CSS, and JavaScript.
